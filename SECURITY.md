# Security policy

GitHub private vulnerability reporting is **not** enabled on this repository.

To report a vulnerability, email **redevops@redevops.io** (the contact listed on the ReDevOps GitHub organization) with a description and reproduction steps. Please do not open a public issue for undisclosed vulnerabilities.

Response times and supported-version policy: contact to be confirmed. Only the latest `main` is considered for fixes; the project is alpha (see [STATUS.md](STATUS.md)).
